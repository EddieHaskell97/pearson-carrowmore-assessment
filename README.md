# Carrowmore Array O&M assessment

This directory contains the bounded Pearson job-application assessment build for the synthetic Carrowmore dataset. It is deliberately isolated from the completed personal classification lab and its SQL mirror.

Scope is fixed to the permitted clean subset of 40 profiles: 38 current keepers are evaluated for interview potential, while K1203 and K1458 are retained in the output as leavers outside the current redeployment cohort. The scenario date is always explicit; the submitted run uses `2026-10-11`.

The evaluator, generated answers, independent QA results, reproducible commands, and design explanation will be completed here. No database, trained classifier, historical test artifact, or existing annotation is used or changed.
